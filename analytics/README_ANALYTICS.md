# Portfolio Analytics Pipeline

This directory contains the Python analytics stack for The Commit Crew trading portfolio management system.

## Quick Start

### 1. Setup

```bash
cd analytics
python -m venv .venv
source .venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Run scripts

```bash
# Run ETL
python -m src.pipeline.etl_pipeline

# Run analysis
python -m src.analysis.analysis_engine

# Run main
python -m src.main run

# Analyze specific symbols and period
python -m src.main run --symbols AAPL IEF SPY --period 1y

# Different periods
python -m src.main run --period 5y
python -m src.main run --period all

# Run the API locally
uvicorn src.api_module:app --host 0.0.0.0 --port 8090
```


### 3. Run tests

```bash
# Run all tests
python -m pytest -v tests

# Run specific test
python -m pytest -v tests/pipeline/test_etl.py

# Run tests coverage
# Needs pytest-cov installed
python -m pytest --cov=src --cov-report=term-missing tests/
```


### 4. API Endpoints

```bash
# Run server
python -m src.api_module
```

Service available on `http://localhost:8090`.

The API provides six endpoints:
- `GET /health` -> checks if service is running
- `POST /analysis` -> runs the complete analysis (statistics + plots)
```bash
curl -X POST "http://127.0.0.1:8090/analysis?tickers=AAPL&tickers=SPY&tickers=IEF&period=1y&volatility_window=30"

```
- `GET /insights` -> returns web report with statistics
```bash
curl "http://localhost:8090/insights?asset_classes=stocks&asset_classes=bonds&period=5y"
```
- `GET /charts/correlation` -> returns correlation heatmap
```bash
curl "http://localhost:8090/charts/correlation?tickers=AAPL&tickers=SPY&tickers=IEF&period=1y"
```
- `GET /charts/volatility` -> return rolling volatility chart
```bash
curl "http://localhost:8090/charts/volatility?tickers=AAPL&tickers=SPY&period=1y&volatility_window=30"
```
- `GET /charts/asset-class-volatility` -> returns the asset-class volatility chart
```bash
curl "http://localhost:8090/charts/asset-class-volatility?tickers=AAPL&tickers=SPY&tickers=IEF&period=1y"
```


### 5. Docker

The `analytics` service exposes the FastAPI application on port 8090.

```bash
# Analytics API logs
docker compose logs -f analytics
```


## Data Retention

CSV files are written to `outputs/csv/` and persist across runs.

### Instruments and Price History Data

Database seed SQL is generated by the analytics pipelines before the database image is built:

1. **MetadataPipeline** writes `outputs/csv/symbol_metadata.csv` and `db/seeds/instruments-data.sql`
2. **ETLPipeline** writes `outputs/csv/price_history.csv` and `db/seeds/price_history-data.sql`
3. **PostgreSQL** loads those generated SQL seeds during database initialization/update

### Data Pipeline

- `python -m src.main run` generates the CSV files and SQL seeds
- Jenkins runs the analytics pipeline before building or updating the database
- PostgreSQL loads the generated files from `/docker-entrypoint-initdb.d/seeds/`

### To update data

Simply re-run Jenkins to regenerate the analytics outputs and update the database.
